# Paper Metadata

This directory contains release metadata for the paper supplementary code package.

- `sample_manifest.csv`: released synthetic examples and their labels/splits.
- `label_definitions.csv`: label and severity coding definitions.
- `splits.csv`: split assignments used by the synthetic smoke-test examples.
- `frozen_artifact_checksums.csv`: checksums for restricted frozen paper
  artifacts used to verify manuscript metrics.
- `e_daic_access.md`: E-DAIC access route, license constraints, and required
  acknowledgements.
- `track_a_inputs.md`: input expectations for the notebook-derived
  syllable/SPM, POS/tense, and sentiment validation scripts.
- `track_a_syllable_spm.md`, `track_a_pos_tense.md`,
  `track_a_sentiment.md`: dataset locations and command examples for each
  Track A validation script.
- `third_party_citations_and_licenses.md`: citation, access, and license
  status for external data, models, and resources referenced by the paper code.
- `paper_file_checksums.csv`: checksums for public paper-folder files.
- `../results/result_file_checksums.csv`: checksums for aggregate paper result
  and source-data files.
- `release_audit.md`: local release hygiene audit for the paper folder.

The released examples are synthetic and are intended for command validation, not
scientific analysis.
