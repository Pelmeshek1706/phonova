# E-DAIC Access And License Notes

This repository does not redistribute E-DAIC data or derived participant-level
paper features. E-DAIC access is controlled by the official data provider.

## Official Access Route

- DAIC-WOZ / Extended DAIC website: https://dcapswoz.ict.usc.edu/
- Use the "APPLY NOW Extended DAIC" route for the Extended DAIC database.
- Use the official site's contact form for access questions.
- The official site states that, because of consent constraints, data can be
  distributed only to academics and other non-profit researchers, and requests
  should use an academic email address.

## EULA Summary

The Extended DAIC EULA requires a signed agreement before data use. Key terms:

- Research use only.
- Commercial use is forbidden.
- Redistribution of the database or any part of it to third parties is forbidden.
- Illustrative use in scientific or educational publications is allowed only
  when subject identity is protected.
- Publications using the data must cite the DAIC-WOZ corpus paper and the AVEC
  2019 paper.
- The provider may change the terms and require a new signed agreement.
- The database is provided without warranty.

## Paper-Specific Implication

The manuscript states that E-DAIC audio, transcripts, machine-translated
transcripts, and derived participant-level features cannot be redistributed by
the authors. Independent Track B reruns therefore require authorized E-DAIC
access plus the public code/configuration in this repository.
